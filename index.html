Web Port

Web ports of PC games, run in your browser from your own copy. This site contains no game files: each game is unpacked on this device from its original PC installer, and stays here.

    On iPhone and iPad, add this site to the Home Screen (Share → Add to Home Screen) and play from there, so Safari keeps the game data.

    About

    Get opens the game's original installer on archive.org; your browser downloads it, then you choose the downloaded file here. The installer is read in your browser: the game is unpacked, its data decrypted and its images converted on this device, then kept in this site's storage for the next visit. The installer itself is not kept. Until a game is on this device, its picture is its mobile version's icon from an archive.org upload; after, it's the PC game's own icon. The PC versions' online activation is no longer in service, so the games run as the full versions, as the mobile versions did. Not affiliated with the games' makers.
